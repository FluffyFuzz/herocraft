# herocraft

## Présentation du projet 
Nous avons décidé de développer un site web de création de personnage inspiré des jeux vidéo, style RPG, notamment Skyrim. Celui-ci s'appellera HeroCraft.

## Fonctionnalités

- Créer et personnaliser son propre personnage.
- Choisir différentes caractéristiques et options de personnalisation.
- Voir son personnage évoluer selon ses choix (attributs). 
- Avoir une représentation 3D du personnage sur la page web.
